Get involved

Use the software, tell us what breaks, or help build it. Funding comes later, once the nonprofit exists.

  • Use it

    Every shipping product can be downloaded and installed today. Town halls, stations, newsrooms and makerspaces that want to try one with real work are exactly who this is built for.

    Find a product

  • Report a problem

    Each product's code page has an issue tracker. A clear report of what you did and what happened is the most useful thing you can send.

  • Help build it

    Code, documentation, testing on real hardware and translations are all welcome. Start with the product you use.

    Fork Commons on GitHub

  • Fund it

    Fork Commons isn't accepting money yet. Once the nonprofit is incorporated, donations and grants will go here, and the open books will show where every dollar goes.
